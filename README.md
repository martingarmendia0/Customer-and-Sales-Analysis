📊 Customer Orders Analysis

📌 Project Overview

This project focuses on analyzing customer and order data to extract meaningful business insights.
Using exploratory data analysis (EDA), the goal is to understand customer behavior, sales performance, and revenue distribution across products and countries.

The analysis is designed as an entry-level data analytics project, emphasizing clarity, reproducibility, and business interpretation.

📂 Dataset Description

The project uses two datasets:

🧑 Customers Dataset

Contains demographic and registration information about customers.

Columns:

customer_id

gender

age

country

signup_date

🛒 Orders Dataset

Contains transactional data related to customer purchases.

Columns:

order_id

customer_id

order_date

order_amount

product_category

🎯 Objectives

Explore customer and order data structure

Calculate key business metrics:

Total revenue

Average Order Value (AOV)

Orders per customer

Analyze revenue distribution:

By product category

By country

Identify top-performing markets

Summarize findings with actionable business insights

🔍 Key Findings

The average order value is stable, suggesting consistent purchasing behavior.

Revenue is concentrated in a small number of product categories.

A few countries generate most of the total revenue.

Some customers place significantly more orders than the average, contributing disproportionately to sales.

📊 Tools & Libraries

Python

Pandas for data manipulation

Matplotlib for data visualization

NumPy for numerical operations

⚠️ Limitations

The dataset is synthetic and may not reflect real-world complexity.

The analysis is descriptive and does not include predictive modeling.

No advanced statistical or machine learning techniques were applied.
